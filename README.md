# Fund Dashboard (OSWE Mini Prime)

Simple React + TypeScript + Tailwind demo for a fund dashboard.

## Requirements
- Node.js (>=18 recommended)
- pnpm

## Run locally
1. Install dependencies:

   pnpm install

2. Start dev server:

   pnpm dev

Open http://localhost:5173

## Notes
- Uses mock data in `src/data/funds.ts`.
- Filter by risk level and sort by NAV or daily change.
