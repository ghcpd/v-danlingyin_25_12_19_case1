Fund Dashboard — React + TypeScript + Tailwind

Quick start (pnpm):

1. Install dependencies
   pnpm install
2. Start dev server
   pnpm dev

Build:
  pnpm build
  pnpm preview

What I added:
- Vite + React + TypeScript project config
- Tailwind CSS config
- Typed mock data (src/types.ts, src/data/funds.ts)
- Simple professional UI with filter (risk) and sorting (NAV / daily % / name)
- Empty state handling and accessible controls

Notes:
- This is a front-end only demo (no backend)
- Uses pnpm as requested
